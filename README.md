# 🌍 Traveloop – All-in-One Travel Companion

Traveloop is a modern travel management web application built using Flask that helps users organize, manage, and document their trips in one place.

The platform provides an intuitive travel planning experience with itinerary management, expense tracking, packing checklists, and personal trip journaling — all wrapped in a clean responsive dark-themed UI.

---

# ✨ Features

## 🧳 Trip Management
- Create and manage trips effortlessly
- Automatically categorize trips into:
  - Ongoing Trips
  - Preplanned Trips
  - Completed Trips
- Smart date-based trip progression logic

---

## 📅 Itinerary Builder
- Build detailed day-wise itineraries
- Add activities dynamically
- Organize plans for each travel day
- Automatically estimate and track expenses

---

## 💰 Expense & Billing Tracker
- Invoice-style expense management
- Add:
  - Expense descriptions
  - Quantity
  - Unit cost
- Automatically calculates:
  - Individual totals
  - Grand trip total

---

## 🎒 Packing Checklist
- Categorized packing sections:
  - Clothing
  - Electronics
  - Documents
  - Essentials
- Real-time progress tracking
- Interactive checklist UI

---

## 📝 Trip Journal
- Maintain personal travel notes
- Save memories and experiences
- Store important addresses and reminders
- Tag entries by:
  - Day
  - Location

---

## 👤 User Profile System
- Upload profile picture
- Edit user information
- View summarized trip overview
- Personalized dashboard experience

---

## 🌙 Responsive Modern UI
- Elegant dark-themed interface
- Responsive across:
  - Desktop
  - Tablet
  - Mobile
- Clean card-based layouts
- Smooth and minimal user experience

# 🚀 Local Execution Instructions

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/abhisatwika26/odoo_traveloop.git
cd odoo_traveloop
```

---

## 2️⃣ Create a Virtual Environment

### For Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### For macOS/Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 4️⃣ Run the Application

```bash
python app.py
```

---

## 5️⃣ Open in Browser

Visit:

```bash
http://127.0.0.1:5000
```
